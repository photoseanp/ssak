### Зачем нужна эта функция

В основном модуле фракционной эффективности предполагается, что upstream- и downstream-концентрации записаны в одном файле измерения. Но в некоторых конфигурациях стенда данные снимаются двумя отдельными сенсорами — SP1 (upstream) и SP2 (downstream), каждый в свой собственный файл. В этом случае:

- в файле **SP1** реальные значения содержит колонка `dCmup` (upstream), а `dCmdown` записан как 0;
- в файле **SP2** реальные значения содержит колонка `dCmdown` (downstream), а `dCmup` записан как 0.

По отдельности ни один из этих файлов не даёт корректную кривую эффективности — новая функция объединяет пару файлов SP1+SP2 одного измерения и считает настоящую эффективность по формуле:

E[%] = (1 - dCmdown_SP2 / dCmup_SP1) x 100

расчёт выполняется отдельно для каждого размерного диапазона (бина) частиц.

### Как пользоваться (после подключения к меню)

1. В главном меню выбрать пункт **"Сравнение фракционной эффективности для раздельных сенсоров"**.
2. Программа покажет пронумерованный список всех `.txt`-файлов в настроенной папке с исходными данными.
3. Ввести номера файлов **SP1** через запятую — в том порядке, в котором нужно сравнить измерения (например: `1,3,5`).
4. Ввести номера файлов **SP2** — в **том же порядке**, что и SP1, чтобы каждая пара соответствовала одному и тому же фильтру и расходу (например: `2,4,6`).
5. Программа автоматически объединит пары, рассчитает эффективность и покажет, сколько точек данных получено по каждой паре.
6. Ввести имя файла для сохранения графика (по умолчанию `frac_eff_split_result`).
7. Готовый график в формате PNG сохраняется в настроенную папку результатов.

Название каждой кривой в легенде графика автоматически формируется из поля `rem.1` файла SP1 с удалением обозначения "SP1" — например, `FEG-PN1-10_SP1 1000lpm` превращается в `FEG-PN1-10 1000lpm`.

### Пример использования (из тестовых файлов)

На вход были поданы файлы измерений фильтра FEG-PN1-10 при трёх расходах:

| SP1 файл | SP2 файл | Расход |
|---|---|---|
| FEG-PN1-10_SP1_1000lpm.txt | FEG-PN1-10_SP2_1000lpm.txt | 1000 л/мин |
| FEG-PN1-10_SP1_2000lpm.txt | FEG-PN1-10_SP2_2000lpm.txt | 2000 л/мин |
| FEG-PN1-10_SP1_3000lpm.txt | FEG-PN1-10_SP2_3000lpm.txt | 3000 л/мин |

### Ограничения текущей реализации новой функции

- Количество выбранных файлов SP1 должно точно совпадать с количеством файлов SP2; при несовпадении программа выводит сообщение об ошибке и не выполняет расчёт.
- Файлы SP1 и SP2 должны иметь одинаковое количество и порядок размерных бинов (Xu/X/Xo) — это стандартное условие для пары измерений одного и того же фильтра на одном приборе.
- Если значение `dCmup` в файле SP1 равно нулю для какого-либо бина, точка пропускается (деление на ноль не выполняется).

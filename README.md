# SATEC Swiss Army Knife (SSAK)

Единая программа с текстовым меню (TUI) для расчёта фильтрационных характеристик мембран и материалов. Объединяет пять инструментов в одном исполняемом файле — без Python, без установки библиотек, без длинных команд запуска.

Поддерживаемые платформы: **Windows** и **macOS** (основные), а также Linux.

## Установка на Windows

### Вариант 1 — готовый файл (рекомендуется)

1. Перейдите в раздел **Releases** репозитория проекта на GitHub.
2. Скачайте файл `ssak-windows-x86_64.exe` из последнего релиза.
3. Создайте отдельную папку, например `C:\SSAK`, и переместите туда скачанный файл.
4. Переименуйте файл в `ssak.exe` для удобства (необязательно).
5. Запустите файл двойным щелчком, либо через командную строку (см. раздел "Первый запуск").

**Важно:** при первом запуске Windows Defender/SmartScreen может показать предупреждение "Windows защитила ваш компьютер", так как файл не подписан цифровой подписью. Нажмите **"Подробнее"** → **"Выполнить в любом случае"**, чтобы продолжить. Это стандартное поведение для непубликуемых в Microsoft Store программ и не означает наличие вредоносного кода.

### Вариант 2 — сборка из исходного кода

Используется, если нужна последняя версия с изменениями, которых ещё нет в готовом релизе. См. раздел [Сборка из исходного кода](#сборка-из-исходного-кода).

## Установка на macOS

### Вариант 1 — готовый файл (рекомендуется)

1. Перейдите в раздел **Releases** репозитория проекта на GitHub.
2. Скачайте нужный файл в зависимости от процессора вашего Mac:
   - `ssak-macos-aarch64` — для Mac с процессором Apple Silicon (M1, M2, M3, M4)
   - `ssak-macos-x86_64` — для Mac с процессором Intel
3. Чтобы узнать тип процессора: нажмите на логотип Apple в левом верхнем углу экрана → **"Об этом Mac"**. Если в разделе "Чип" указано "Apple M1/M2/M3/M4" — используйте aarch64-версию, если "Intel" — используйте x86_64-версию.
4. Переместите скачанный файл в отдельную папку, например `~/SSAK/`.
5. Откройте **Terminal** (Терминал) и сделайте файл исполняемым:
   ```
   chmod +x ~/SSAK/ssak-macos-aarch64
   ```
6. Запустите программу (см. раздел "Первый запуск").

**Важно (Gatekeeper):** при первом запуске macOS покажет предупреждение вида "невозможно открыть файл, так как он от неизвестного разработчика". Это нормально для файлов, скачанных не из App Store. Чтобы разрешить запуск:

- Способ А: щёлкните по файлу правой кнопкой мыши (или Control+клик) → **"Открыть"** → в диалоговом окне подтвердите **"Открыть"**.
- Способ Б: откройте **Системные настройки → Конфиденциальность и безопасность**, найдите внизу сообщение о блокировке ssak и нажмите **"Открыть в любом случае"**.

После первого разрешённого запуска предупреждение больше не появляется.

## Первый запуск и настройка папок

### Запуск программы

**Windows** (через командную строку, из папки с файлом):
```
ssak.exe
```

**macOS** (через Терминал, из папки с файлом):
```
./ssak-macos-aarch64
```
(замените имя файла на актуальное для вашего процессора)

Совет: чтобы не набирать полный путь каждый раз, откройте Терминал/командную строку непосредственно в папке с программой:
- **Windows:** в Проводнике откройте нужную папку, в адресной строке введите `cmd` и нажмите Enter.
- **macOS:** в Finder откройте нужную папку, затем в меню **Finder → Службы → Открыть Терминал здесь** (или зажмите Control при клике по папке).

### Настройка папок ввода/вывода

При первом запуске программа предложит настроить:
- **Папку с исходными данными** — где лежат ваши файлы с измерениями.
- **Папку для результатов** — куда будут сохраняться сгенерированные графики.

Это делается один раз через пункт меню **"Настройка папок (вход/выход)"**. Настройки сохраняются в файл `ssak_config.json` рядом с программой и автоматически подгружаются при всех следующих запусках — вводить пути повторно не требуется.

Пример настройки:

| Параметр | Windows | macOS |
|---|---|---|
| Папка с исходными данными | `C:\SSAK\input` | `~/SSAK/input` |
| Папка для результатов | `C:\SSAK\output` | `~/SSAK/output` |

## Использование инструментов

После запуска программы отображается главное меню. Перемещение — стрелками вверх/вниз, выбор — клавишей Enter.

| Инструмент | Что делает | Что нужно ввести | Результат |
|---|---|---|---|
| Точка пузырька | Расчёт диаметра пор мембраны | Давление точки пузырька (бар) | Диаметр пор в мкм на экране |
| Воздухопроницаемость (линейная) | Коэффициент проницаемости по линейной модели | Расход, площадь, перепад давления | Коэффициент на экране |
| Воздухопроницаемость (степенная) | Коэффициент проницаемости со степенной моделью | Расход, площадь, давление, показатель n | Коэффициент на экране |
| Парсер дифференциального давления | Обработка серии измерений и построение графика | Имя файла из папки исходных данных | PNG-график в папке результатов |
| Фракционная эффективность | Сравнение эффективности фильтрации нескольких образцов | Имя файла из папки исходных данных | PNG-график в папке результатов |

Для парсеров (дифференциальное давление и фракционная эффективность) достаточно ввести **только имя файла** (например, `TGC_10-1030.txt`) — программа сама найдёт его в настроенной папке с исходными данными и сохранит результат в папку результатов.

### Формат входных файлов

Текстовый файл (CSV/TXT), разделитель — запятая, точка с запятой или табуляция. Первая строка — заголовок (пропускается автоматически), далее — числовые пары значений.

## Сборка из исходного кода

Требуется, если нужна последняя версия из ветки `main`, либо вы вносите изменения в код.

### Шаг 1 — установка Rust

**Windows:**
Скачайте и запустите `rustup-init.exe` с [rust-lang.org/tools/install](https://www.rust-lang.org/tools/install), следуйте инструкциям установщика (можно оставить настройки по умолчанию).

**macOS:**
Откройте Терминал и выполните:
```
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
После установки перезапустите Терминал или выполните `source $HOME/.cargo/env`.

### Шаг 2 — клонирование и сборка

```
git clone <URL-репозитория>
cd ssak
cargo build --release
```

Готовый файл появится по пути:
- Windows: `target\release\ssak.exe`
- macOS: `target/release/ssak`

### Шаг 3 — CI/CD (для команды разработки)

- `ci.yml` — автосборка и тесты на Windows, macOS и Linux при каждом push/pull request.
- `release.yml` — при пуше тега `v*.*.*` собирает и публикует бинарники для всех платформ в GitHub Releases.

```
git tag v0.1.0
git push origin v0.1.0
```

## Частые проблемы

| Проблема | Решение |
|---|---|
| Windows блокирует запуск ("SmartScreen") | Нажмите "Подробнее" → "Выполнить в любом случае" |
| macOS не даёт открыть файл ("неизвестный разработчик") | ПКМ/Control+клик по файлу → "Открыть" → подтвердить |
| macOS: "Permission denied" при запуске | Выполните `chmod +x <имя_файла>` перед запуском |
| Программа не находит файл с данными | Проверьте, что файл лежит именно в настроенной папке исходных данных и имя введено с расширением |
| Нужно изменить папки после первой настройки | В главном меню выберите "Настройка папок (вход/выход)" |
| Не знаю тип процессора Mac | Apple-логотип → "Об этом Mac" → раздел "Чип" |

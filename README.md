# SATEC Swiss Army Knife (SSAK)

Единая программа с TUI-меню, объединяющая инженерные расчёты и парсеры
Palace для обработки данных испытаний фильтрующих материалов: расчёт
воздухопроницаемости, размера пор, парсинг дифференциального давления и
фракционной эффективности.

Вместо нескольких отдельных программ теперь один исполняемый файл -- `ssak`.
При запуске он показывает меню, где стрелками Вверх/Вниз выбирается нужный
инструмент, а Enter его запускает. Отдельно есть пункт меню для настройки
папки с исходными данными и папки для сохранения результатов -- один раз
указали пути, дальше их не нужно вводить заново.

## Быстрый старт

```bash
git clone <URL-репозитория>
cd ssak
cargo build --release

# Linux / macOS
./target/release/ssak

# Windows
.\target\release\ssak.exe
```

При первом запуске откройте пункт меню "Настройка папок (вход/выход)" и
укажите:
- папку, где лежат файлы данных (`.txt`, `.pal`);
- папку, куда сохранять результаты (графики PNG).

Настройки сохраняются в файл `ssak_config.json` рядом с программой и
подхватываются автоматически при следующих запусках -- вводить пути
повторно не нужно.

## Меню программы

```
================ SATEC Swiss Army Knife (SSAK) ================
Папка данных: ...   |   Папка вывода: ...
=================================================================
> Расчёт размера пор (точка пузырька)
  Воздухопроницаемость -- линейная модель
  Воздухопроницаемость -- степенная модель
  Парсер дифференциального давления
  Сравнение фракционной эффективности
  Настройка папок (вход/выход)
  Выход
```

Управление: стрелки Вверх/Вниз для выбора пункта, Enter -- запустить.
После завершения расчёта программа возвращает вас в это же меню.

## Установка Rust (один раз)

### Windows
Скачать и запустить `rustup-init.exe` с [rustup.rs](https://rustup.rs),
выбрать установку по умолчанию, перезапустить терминал.

### macOS
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
```

### Linux
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
sudo apt install build-essential pkg-config   # Debian/Ubuntu
```

## Состав инструментов

| Инструмент | Назначение |
|---|---|
| Расчёт размера пор | Метод точки пузырька (ИПС) |
| Воздухопроницаемость -- линейная модель | Линейная регрессия ΔP-Q, доверительные интервалы |
| Воздухопроницаемость -- степенная модель | ΔP = k·Qⁿ, МНК в логарифмах |
| Парсер дифференциального давления | Обработка .txt/.pal из папки данных, график PNG в папку вывода |
| Сравнение фракционной эффективности | Сравнение кривых эффективности фильтров, график PNG |

## Известные ограничения текущей версии

- Графики сохраняются только в PNG, отдельного окна предпросмотра нет.

## Поддержка

Внутренний инструмент компании Palace.

# SATEC Swiss Army Knife (SSAK)

SSAK — набор инструментов для расчёта и анализа фильтрационных характеристик, собранный в единое консольное TUI-приложение. Написан на Rust, работает одинаково на Windows, macOS и Linux.

## Состав инструментов

- Расчёт размера пор (точка пузырька)
- Воздухопроницаемость — линейная модель
- Воздухопроницаемость — степенная модель
- Парсер дифференциального давления (с построением графика)
- Сравнение фракционной эффективности (с построением графика)
- Менеджер путей ввода/вывода

Все инструменты вызываются из одного главного меню без необходимости заучивать команды или параметры.

## Prerequisites

Если вы скачиваете готовый бинарник из раздела [Releases](https://github.com/photoseanp/ssak/releases) — дополнительные зависимости не нужны — бинарник собран статически и готов к запуску сразу.

Готовить окружение нужно только если вы собираете проект из исходного кода:

- **Rust и Cargo** (версия 1.70 или выше). Ставится через [rustup.rs](https://rustup.rs/).
- **Git** — для клонирования репозитория.
- На Linux также понадобится стандартный набор инструментов сборки (`build-essential` или аналог).

Системные библиотеки типа fontconfig не требуются — все графики рисуются встроенными средствами Rust-крейта `plotters`.

## Установка

### Вариант 1 — готовый бинарник (рекомендуется)

1. Откройте страницу [Releases](https://github.com/photoseanp/ssak/releases) и скачайте файл для вашей операционной системы:
   - Windows — `ssak-windows-x86_64.exe`
   - macOS (Intel) — `ssak-macos-x86_64`
   - macOS (Apple Silicon, M1/M2/M3) — `ssak-macos-aarch64`
   - Linux — `ssak-linux-x86_64`

2. **Windows**: запустите `ssak-windows-x86_64.exe` двойным кликом или из PowerShell/CMD.

3. **macOS**: откройте Terminal и выдайте разрешение на выполнение, так как macOS блокирует бинарники, скачанные из интернета, по умолчанию:
   ```bash
   chmod +x ssak-macos-x86_64   # или ssak-macos-aarch64 для Apple Silicon
   xattr -d com.apple.quarantine ssak-macos-x86_64
   ./ssak-macos-x86_64
   ```

4. **Linux**: дайте файлу права на исполнение и запустите:
   ```bash
   chmod +x ssak-linux-x86_64
   ./ssak-linux-x86_64
   ```

5. (Опционально) для удобства переместите исходный бинарник в папку, входящую в PATH, чтобы запускать программу просто командой `ssak` из любой папки.

### Вариант 2 — сборка из исходного кода

1. Установите Rust через [rustup.rs](https://rustup.rs/) (одинаково для Windows/macOS/Linux):
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```
   На Windows скачайте и запустите `rustup-init.exe` с той же страницы.

2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/photoseanp/ssak.git
   cd ssak
   ```

3. Соберите релизную версию:
   ```bash
   cargo build --release
   ```

4. Готовый исполняемый файл появится в:
   - Windows: `target\release\ssak.exe`
   - macOS/Linux: `target/release/ssak`

5. Запустите:
   ```bash
   ./target/release/ssak
   ```

## Запуск программы

После запуска откроется главное меню. Выберите нужный инструмент стрелками и нажмите Enter. Перед первым использованием рекомендуется зайти в пункт **"Настройка папок (вход/выход)"** и указать:

- папку с исходными данными (откуда парсеры будут считывать входные файлы),
- папку для результатов (туда будут сохраняться графики и выводы расчётов).

Настройки сохраняются в файл `ssak_config.json` рядом с программой и подхватываются автоматически при каждом следующем запуске — вводить пути каждый раз не нужно.

## CI/CD

При каждом push в `main` автоматически запускается сборка на Windows, macOS и Linux (`ci.yml`). При создании тега вида `v*.*.*` автоматически собираются и публикуются релизные бинарники под все 4 платформы (`release.yml`).

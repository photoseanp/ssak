# SATEC Swiss Army Knife (SSAK)

SSAK — набор инструментов для расчёта и анализа фильтрационных характеристик, собранный в единое консольное TUI-приложение. Написан на Rust, работает одинаково на Windows, macOS и Linux.

## Состав инструментов

- Расчёт размера пор (точка пузырька)
- Воздухопроницаемость — линейная модель
- Воздухопроницаемость — степенная модель
- Парсер дифференциального давления (с выбором файла из папки, с построением графика)
- Сравнение фракционной эффективности (с выбором файла из папки, с построением графика)
- Менеджер путей ввода/вывода с проверкой существования папок

Все инструменты вызываются из одного главного меню без необходимости заучивать команды или параметры. В любом поле ввода можно набрать q и нажать Enter, чтобы отменить текущий инструмент и вернуться в главное меню, а на экране после завершения расчёта — ввести q ещё раз, чтобы выйти из программы.

## Prerequisites

Если вы скачиваете готовый бинарник из раздела [Releases](https://github.com/photoseanp/ssak/releases) — дополнительные зависимости не нужны — бинарник собран статически и готов к запуску сразу.

Готовить окружение нужно только если вы собираете проект из исходного кода:

- **Rust и Cargo** (версия 1.70 или выше). Ставится через [rustup.rs](https://rustup.rs/).
- **Git** — для клонирования репозитория.
- На Linux также понадобится стандартный набор инструментов сборки (`build-essential` или аналог).

Системные библиотеки типа fontconfig не требуются — все графики рисуются встроенными средствами Rust-крейта `plotters`.

## Установка

### Вариант 1 — готовый бинарник (рекомендуется)

1. Откройте страницу [Releases](https://github.com/photoseanp/ssak/releases) и скачайте файл для вашей операционной системы:
   - Windows — `ssak-windows-x86_64.exe`
   - macOS (Intel) — `ssak-macos-x86_64`
   - macOS (Apple Silicon, M1/M2/M3) — `ssak-macos-aarch64`
   - Linux — `ssak-linux-x86_64`

2. **macOS**: откройте Terminal и выдайте разрешение на выполнение:
   ```bash
   chmod +x ssak-macos-x86_64   # или ssak-macos-aarch64 для Apple Silicon
   xattr -d com.apple.quarantine ssak-macos-x86_64
   ```

3. **Linux**: дайте файлу права на исполнение:
   ```bash
   chmod +x ssak-linux-x86_64
   ```

### Вариант 2 — сборка из исходного кода

1. Установите Rust через [rustup.rs](https://rustup.rs/) (одинаково для Windows/macOS/Linux):
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```
   На Windows скачайте и запустите `rustup-init.exe` с той же страницы.

2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/photoseanp/ssak.git
   cd ssak
   ```

3. Соберите релизную версию:
   ```bash
   cargo build --release
   ```

4. Готовый исполняемый файл появится в:
   - Windows: `target\release\ssak.exe`
   - macOS/Linux: `target/release/ssak`

## Запуск командой `ssak` (без длинных имён)

Скачанный файл имеет длинное имя (например `ssak-macos-x86_64`), чтобы различать релизы под разные платформы. Чтобы затем всегда запускать программу просто командой `ssak`, выполните одноразовую настройку.

### macOS / Linux

Переместите скачанный файл в системную папку и переименуйте в `ssak`:

```bash
sudo mv ssak-macos-x86_64 /usr/local/bin/ssak   # замените имя файла на своё
sudo chmod +x /usr/local/bin/ssak
```

После этого программа запускается из любой терминальной папки командой:

```bash
ssak
```

Альтернатива без копирования в системную папку — создать символическую ссылку из текущего расположения файла:

```bash
chmod +x ssak-macos-x86_64
sudo ln -s "$(pwd)/ssak-macos-x86_64" /usr/local/bin/ssak
```

### Windows

1. Создайте постоянную папку для программы, например `C:\Tools\ssak\`.
2. Переместите скачанный файл туда и переименуйте его в `ssak.exe`.
3. Добавьте эту папку в PATH: нажмите Пуск → введите «environment variables» → «Изменить переменные среды для вашей учётной записи» → в строке Path нажать «Изменить» → «Создать» → вставить `C:\Tools\ssak\`.
4. Перезапустите PowerShell или командную строку.
5. Теперь программа запускается из любой папки командой:

   ```powershell
   ssak
   ```

## Установка из исходного кода

Завершить запуск одной командой `ssak` можно и после сборки из исходников (см. «Вариант 2» выше): после `cargo build --release` выполните `sudo cp target/release/ssak /usr/local/bin/ssak` (macOS/Linux) или скопируйте `target\release\ssak.exe` в папку в PATH (Windows).

## Запуск программы

После запуска открывается главное меню. Выберите нужный инструмент стрелками и нажмите Enter. Перед первым использованием рекомендуется зайти в пункт «Настройка папок (вход/выход)» и указать существующие папки: папку с исходными данными и папку для результатов. При проверке программа явно сообщает, найдена ли папка, а если папка результатов не найдена — спросит разрешение на её создание.

Настройки сохраняются в файл `ssak_config.json` рядом с программой и подхватываются автоматически при каждом следующем запуске.

Для выхода из любого инструмента обратно в главное меню введите `q` в любом текстовом поле ввода. А чтобы завершить работу самой программы — введите `q` на экране «Нажмите Enter для возврата в меню», который появляется после каждого расчёта, либо выберите пункт «Выход» в главном меню.

## CI/CD

При каждом push в `main` автоматически запускается сборка на Windows, macOS и Linux (`ci.yml`). При создании тега вида `v*.*.*` автоматически собираются и публикуются релизные бинарники под все 4 платформы (`release.yml`).

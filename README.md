# SATEC Swiss Army Knife (SSAK)

Единая программа с текстовым меню (TUI) для расчёта фильтрационных характеристик мембран и материалов. Объединяет пять инструментов в одном исполняемом файле — без Python, без установки библиотек, без длинных команд запуска.

Поддерживаемые платформы: **Windows**, **macOS** и **Linux**.

## Установка на Windows

### Вариант 1 — готовый файл (рекомендуется)

1. Перейдите в раздел **Releases** репозитория проекта на GitHub.
2. Скачайте файл `ssak-windows-x86_64.exe` из последнего релиза.
3. Создайте отдельную папку, например `C:\SSAK`, и переместите туда скачанный файл.
4. **Переименуйте файл в `ssak.exe`** (обязательно для запуска короткой командой, см. раздел 4).
5. Запустите файл двойным щелчком, либо через командную строку (см. раздел "Первый запуск").

**Важно:** при первом запуске Windows Defender/SmartScreen может показать предупреждение "Windows защитила ваш компьютер", так как файл не подписан цифровой подписью. Нажмите **"Подробнее"** → **"Выполнить в любом случае"**, чтобы продолжить. Это стандартное поведение для непубликуемых в Microsoft Store программ и не означает наличие вредоносного кода.

### Вариант 2 — сборка из исходного кода

Используется, если нужна последняя версия с изменениями, которых ещё нет в готовом релизе. См. раздел [Сборка из исходного кода](#сборка-из-исходного-кода).

## Установка на macOS

### Вариант 1 — готовый файл (рекомендуется)

1. Перейдите в раздел **Releases** репозитория проекта на GitHub.
2. Скачайте нужный файл в зависимости от процессора вашего Mac:
   - `ssak-macos-aarch64` — для Mac с процессором Apple Silicon (M1, M2, M3, M4)
   - `ssak-macos-x86_64` — для Mac с процессором Intel
3. Чтобы узнать тип процессора: нажмите на логотип Apple в левом верхнем углу экрана → **"Об этом Mac"**. Если в разделе "Чип" указано "Apple M1/M2/M3/M4" — используйте aarch64-версию, если "Intel" — используйте x86_64-версию.
4. Переместите скачанный файл в отдельную папку, например `~/SSAK/`.
5. **Переименуйте файл в `ssak`** (без расширения — обязательно для запуска короткой командой, см. раздел 4).
6. Откройте **Terminal** (Терминал) и сделайте файл исполняемым:
   ```
   chmod +x ~/SSAK/ssak
   ```
7. Запустите программу (см. раздел "Первый запуск").

**Важно (Gatekeeper):** при первом запуске macOS покажет предупреждение вида "невозможно открыть файл, так как он от неизвестного разработчика". Это нормально для файлов, скачанных не из App Store. Чтобы разрешить запуск:

- Способ А: щёлкните по файлу правой кнопкой мыши (или Control+клик) → **"Открыть"** → в диалоговом окне подтвердите **"Открыть"**.
- Способ Б: откройте **Системные настройки → Конфиденциальность и безопасность**, найдите внизу сообщение о блокировке ssak и нажмите **"Открыть в любом случае"**.

После первого разрешённого запуска предупреждение больше не появляется.

## Установка на Linux

Программа полностью поддерживает Linux (сборка для архитектуры x86_64). Рекомендуемый способ — использование готового файла из раздела Releases.

### Пошаговая установка

1. Перейдите в раздел **Releases** репозитория проекта на GitHub.
2. Скачайте файл `ssak-linux-x86_64` из последнего релиза.
3. Создайте отдельную постоянную папку, например `~/ssak/`, и переместите туда скачанный файл.
4. **Переименуйте файл в `ssak`** (без расширения — обязательно для запуска короткой командой, см. раздел 4).
5. Откройте терминал и сделайте файл исполняемым:
   ```
   chmod +x ssak
   ```
6. Запустите программу из папки с файлом:
   ```
   ./ssak
   ```

### Возможные ограничения при запуске

В отличие от Windows и macOS, Linux не имеет единой системы предупреждений о неподписанных файлах — достаточно установить права на выполнение (`chmod +x`). Возможные особенности в зависимости от дистрибутива:

- Если система сообщает **"Permission denied"** — убедитесь, что выполнена команда `chmod +x ssak`.
- Если система сообщает **"cannot execute binary file"** — проверьте, что скачан файл именно для архитектуры x86_64, соответствующей вашему процессору.
- На некоторых минимальных дистрибутивах (например, Alpine Linux с musl) может потребоваться установка пакета glibc-совместимости, если сборка линкована динамически.

## Запуск простой командой ssak

По умолчанию для запуска программы нужно находиться в папке с файлом и вводить полный путь. Чтобы запускать программу командой `ssak` из любой папки и любого места в терминале, нужно один раз добавить папку с программой в системную переменную **PATH**.

### Windows

1. Убедитесь, что файл называется `ssak.exe` и лежит в постоянной папке, например `C:\SSAK`.
2. Нажмите **Win** и введите "переменные среды", откройте **"Изменение переменных среды текущего пользователя"**.
3. В списке **"Переменные пользователя"** найдите переменную **Path**, выберите её и нажмите **"Изменить"**.
4. Нажмите **"Создать"** и добавьте путь к папке: `C:\SSAK`.
5. Нажмите **ОК** во всех окнах, чтобы сохранить изменения.
6. Откройте **новое** окно командной строки (PowerShell или cmd) и проверьте:
   ```
   ssak
   ```
   Программа должна запуститься без указания полного пути.

**Альтернатива без изменения PATH:** создайте на Рабочем столе ярлык для `ssak.exe` — двойной клик по ярлыку запускает программу без командной строки.

### macOS

1. Убедитесь, что файл называется `ssak`, исполняемый (`chmod +x ssak`) и лежит в постоянной папке, например `~/SSAK/`.
2. Откройте Терминал и определите, какой shell используется по умолчанию:
   ```
   echo $SHELL
   ```
3. В зависимости от результата откройте нужный файл конфигурации:
   - Если результат содержит `zsh` (стандарт для macOS начиная с Catalina) — откройте `~/.zshrc`:
     ```
     nano ~/.zshrc
     ```
   - Если результат содержит `bash` — откройте `~/.bash_profile`:
     ```
     nano ~/.bash_profile
     ```
4. Добавьте в конец файла строку (укажите свой реальный путь к папке):
   ```
   export PATH="$HOME/SSAK:$PATH"
   ```
5. Сохраните файл (в nano: Ctrl+O, затем Enter, затем Ctrl+X для выхода).
6. Примените изменения в текущей сессии терминала:
   ```
   source ~/.zshrc
   ```
   (или `source ~/.bash_profile`, если используется bash)
7. Проверьте:
   ```
   ssak
   ```
   Программа должна запуститься из любой папки.

После этой настройки новые окна Терминала будут автоматически подхватывать команду `ssak` без дополнительных действий.

### Linux

Способ аналогичен macOS, так как обе системы используют похожие командные оболочки. Большинство современных дистрибутивов Linux используют bash по умолчанию.

1. Убедитесь, что файл называется `ssak`, исполняемый (`chmod +x ssak`) и лежит в постоянной папке, например `~/ssak/`.
2. Откройте терминал и определите используемый shell:
   ```
   echo $SHELL
   ```
3. Откройте файл конфигурации, соответствующий вашей оболочке: `~/.bashrc` для bash или `~/.zshrc` для zsh.
   ```
   nano ~/.bashrc
   ```
4. Добавьте в конец файла строку (укажите свой реальный путь к папке):
   ```
   export PATH="$HOME/ssak:$PATH"
   ```
5. Сохраните файл и примените изменения:
   ```
   source ~/.bashrc
   ```
6. Проверьте:
   ```
   ssak
   ```
   Программа должна запуститься из любой папки.

**Альтернативный способ для Linux:** переместить исполняемый файл в системную папку `/usr/local/bin` (требует прав администратора), которая обычно уже добавлена в PATH по умолчанию:
```
sudo mv ssak /usr/local/bin/ssak
```
После этого команда `ssak` сразу доступна из любой папки без правки конфигурационных файлов оболочки.

## Первый запуск и настройка папок

### Запуск программы

После настройки PATH (раздел выше) запуск выполняется одной командой из любого места:
```
ssak
```

Если PATH не настроен, запуск выполняется из папки с файлом:

| Платформа | Команда запуска (из папки с файлом) |
|---|---|
| Windows (командная строка) | `ssak.exe` |
| macOS (Терминал) | `./ssak` |
| Linux (терминал) | `./ssak` |

### Настройка папок ввода/вывода

При первом запуске программа предложит настроить:
- **Папку с исходными данными** — где лежат ваши файлы с измерениями.
- **Папку для результатов** — куда будут сохраняться сгенерированные графики.

Это делается один раз через пункт меню **"Настройка папок (вход/выход)"**. Настройки сохраняются в файл `ssak_config.json` рядом с программой и автоматически подгружаются при всех следующих запусках — вводить пути повторно не требуется.

Пример настройки:

| Параметр | Windows | macOS | Linux |
|---|---|---|---|
| Папка с исходными данными | `C:\SSAK\input` | `~/SSAK/input` | `~/ssak/input` |
| Папка для результатов | `C:\SSAK\output` | `~/SSAK/output` | `~/ssak/output` |

## Использование инструментов

После запуска программы отображается главное меню. Перемещение — стрелками вверх/вниз, выбор — клавишей Enter.

| Инструмент | Что делает | Что нужно ввести | Результат |
|---|---|---|---|
| Точка пузырька | Расчёт диаметра пор мембраны | Давление точки пузырька (бар) | Диаметр пор в мкм на экране |
| Воздухопроницаемость (линейная) | Коэффициент проницаемости по линейной модели | Расход, площадь, перепад давления | Коэффициент на экране |
| Воздухопроницаемость (степенная) | Коэффициент проницаемости со степенной моделью | Расход, площадь, давление, показатель n | Коэффициент на экране |
| Парсер дифференциального давления | Обработка серии измерений и построение графика | Имя файла из папки исходных данных | PNG-график в папке результатов |
| Фракционная эффективность | Сравнение эффективности фильтрации нескольких образцов | Имя файла из папки исходных данных | PNG-график в папке результатов |

Для парсеров (дифференциальное давление и фракционная эффективность) достаточно ввести **только имя файла** (например, `TGC_10-1030.txt`) — программа сама найдёт его в настроенной папке с исходными данными и сохранит результат в папку результатов.

### Формат входных файлов

Текстовый файл (CSV/TXT), разделитель — запятая, точка с запятой или табуляция. Первая строка — заголовок (пропускается автоматически), далее — числовые пары значений.

## Сборка из исходного кода

Требуется, если нужна последняя версия из ветки `main`, либо вы вносите изменения в код.

### Шаг 1 — установка Rust

| Платформа | Команда установки |
|---|---|
| Windows | Скачайте и запустите `rustup-init.exe` с [rust-lang.org/tools/install](https://www.rust-lang.org/tools/install) |
| macOS | `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs \| sh` |
| Linux | `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs \| sh` |

После установки на macOS/Linux перезапустите терминал или выполните `source $HOME/.cargo/env`.

### Шаг 2 — клонирование и сборка

```
git clone <URL-репозитория>
cd ssak
cargo build --release
```

Готовый файл появится по пути:

| Платформа | Путь к готовому файлу |
|---|---|
| Windows | `target\release\ssak.exe` |
| macOS | `target/release/ssak` |
| Linux | `target/release/ssak` |

Скопируйте его в постоянную папку и настройте PATH согласно разделу выше, чтобы использовать короткую команду `ssak`.

### Шаг 3 — CI/CD (для команды разработки)

- `ci.yml` — автосборка и тесты на Windows, macOS и Linux при каждом push/pull request.
- `release.yml` — при пуше тега `v*.*.*` собирает и публикует бинарники для всех платформ (Windows x86_64, macOS x86_64/aarch64, Linux x86_64) в GitHub Releases.

```
git tag v0.1.0
git push origin v0.1.0
```

## Частые проблемы

| Проблема | Решение |
|---|---|
| Windows блокирует запуск ("SmartScreen") | Нажмите "Подробнее" → "Выполнить в любом случае" |
| macOS не даёт открыть файл ("неизвестный разработчик") | ПКМ/Control+клик по файлу → "Открыть" → подтвердить |
| macOS/Linux: "Permission denied" при запуске | Выполните `chmod +x ssak` перед запуском |
| Linux: "cannot execute binary file" | Проверьте, что скачан файл для архитектуры x86_64, соответствующей вашему процессору |
| Команда ssak не найдена после настройки PATH | Откройте новое окно терминала/командной строки — изменения PATH не применяются к уже открытым сессиям |
| Программа не находит файл с данными | Проверьте, что файл лежит именно в настроенной папке исходных данных и имя введено с расширением |
| Нужно изменить папки после первой настройки | В главном меню выберите "Настройка папок (вход/выход)" |
| Не знаю тип процессора Mac | Apple-логотип → "Об этом Mac" → раздел "Чип" |

## Ограничения текущей версии

- Входные файлы должны быть в текстовом формате (CSV/TXT); Excel и другие бинарные форматы не поддерживаются напрямую.
- Инструмент KZD (счётная концентрация частиц) исключён из текущей версии программы.
- Графический интерфейс отсутствует — используется только текстовое меню (TUI).
- Сборки Linux ориентированы на архитектуру x86_64; для ARM-архитектуры (например, Raspberry Pi) требуется отдельная сборка из исходного кода.
